Create a modern, minimalistic web application with a University of Michigan-inspired design (Michigan Maize & Blue color palette, clean typography, generous spacing, subtle shadows, and rounded corners). The interface should feel professional, intuitive, and polished without unnecessary visual clutter.
Application Title
Emerging Risk Deep Evaluation (DRDE)

Home Screen
The homepage should be extremely simple.
Display the title Emerging Risk Deep Evaluation (DRDE) prominently at the top.
Below the title, place a single large centered button labeled:
Configure
The page should have smooth fade/slide animations when loading.

Send the prompt to Google Gemini.

Email the generated report to the recipient entered in the configuration modal.

keep the report available,
allow retrying the email without rerunning the AI analysis.
